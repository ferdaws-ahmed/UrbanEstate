## 📋 Project Overview

Urban Estate is a comprehensive real estate marketplace designed to simplify property transactions for buyers, sellers, and administrators. Built with modern web technologies, the platform offers a seamless user experience with features like interactive property listings, advanced search, multi-role dashboards, and more.

From browsing properties to managing listings and user accounts, Urban Estate provides a one-stop solution for all real estate needs with an emphasis on beautiful design and smooth functionality.

---

## ✨ Features

### 🎨 Beautiful, Modern UI
- **Dark & Light Mode**: Elegant theme switching with persistent preferences
- **Smooth Animations**: Powered by Framer Motion for fluid transitions
- **3D Property Visualization**: Interactive 3D previews with React Three Fiber
- **Responsive Design**: Perfect across all screen sizes from mobile to desktop

### 🔐 Multi-Role System
- **Admin Dashboard**: Full property, user, and seller management capabilities
- **Seller Dashboard**: Create, list, edit, and track property listings with analytics
- **User Dashboard**: Browse properties, save favorites, and make inquiries

### 🛠️ Advanced Features
- **Property Comparison**: Compare multiple properties side-by-side with detailed analysis
- **Interactive Maps**: Leaflet-powered maps for location-based property discovery
- **Live Support Chat**: Real-time communication system between users, sellers, and admins
- **Payment Integration**: Secure payment processing for premium listings and transactions
- **Media Upload**: Drag-and-drop property image upload with preview functionality
- **Property Filtering**: Advanced filtering options by price, location, size, and amenities
- **Featured Properties**: Highlight premium listings on the home page
- **Notification System**: Real-time notifications for updates, messages, and transactions
